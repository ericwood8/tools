# tools
Claude Code generic tools (Python 3, no packages; one PowerShell script and one SQL file that a Python tool runs). Repo-specific tools live in the repo (CodeGenNew: `Docs/Verification/Tools`; CriticalViewer: `tools/deploy/lightsail`).

| Script | Use |
|---|---|
| `edit_text.py` | Exact-count replace that keeps CRLF. `replace_in_file` for one pair, `replace_many` or `FILE --json EDITS.json` for several (all or nothing). Use instead of a one-off script for a multi-line edit. |
| `run_frontend_tests.py` | Installs (when needed) and runs the tests of a React or Angular app folder; prints the summary. |
| `compare_trees.py` | Two source trees matched by file name (a prefix such as `E_` ignored): same, different, only in A, only in B. Comments, blank lines and line endings do not count. For generated against hand-written code. |
| `run_logged.py` | Runs a long command into a log and ends with `FINISHED exit=N`. Start it with `run_in_background: true` so the harness notifies when it ends; no polling, no subshell `&`. |
| `spec_item.py` | `list`, `show`, `move` (spec to completed, optional new heading) and `append` for the numbered `## N.` items of the CodeGenPossibilities spec files; keeps each file's line endings. |
| `sql_run.py` | One guarded SQL statement against MySQL, PostgreSQL or SQL Server through the engine's own client (found on PATH or in Program Files, or borrowed from a running container with `--via`). Refuses a second statement, `GO` and client commands (exit 2); 10 s connect and 30 s query timeouts (exit 124); stops at 10000 rows; the password only travels in `MYSQL_PWD`, `PGPASSWORD` or `SQLCMDPASSWORD` and is redacted from output; notes a statement that cannot be run twice. `--read-only`, `--allow-multi` (a reviewed seed file), `--dry-run`, `--self-test`. |
| `bedrock_probe.py` | AWS Bedrock without boto3: `whoami` (root, IAM user or role, and the account), `models` and `profiles` (which model ids need an inference profile), `converse "prompt"`. Signs requests itself (SigV4) or uses a Bedrock API key; credentials from the environment, the project's .NET user secrets (`--user-secrets DIR`) or the AWS CLI profile, never printed. Explains the usual errors (Error 002, missing inference profile, IAM, signature, expired key). |
| `cargo_vs.py` | `cargo` run in a crate folder after loading the Visual Studio Build Tools environment (`vcvars64.bat`, found with vswhere), so a Rust build links from any shell. `python cargo_vs.py <folder> test --test api queue`; wrap a long build in `run_logged.py`. |
| `run_sql_folder.py` | Every `.sql` file of a folder against one SQL Server database with `sqlcmd` (`-E`, or `--user` with `SQLCMDPASSWORD`), in name order; a failed file is retried after the others while a pass makes progress, so scripts that need each other's objects settle. One line per file, ends `ok=N failed=M`. For a generated project's `sql` folder. |
| `cs_snippet_check.py` | Compiles a C# snippet (`-e "code"` or files) in a throwaway net10.0 project and prints each compiler error once as `CODE file(line,col) message`; `--run` also runs it, `--warnings` lists warnings, `--package ID@VERSION` adds a NuGet package (`--offline` restores only from the local cache, no download). For checking a claim about the compiler in seconds instead of building a mini project by hand. Exit 0 built, 1 errors, 3 restore failed. |
| `throwaway_db.py` | A throwaway MySQL server in Docker: `up` (random root password, bound to 127.0.0.1, waits for a real connection, `--skip-log-bin` for trigger tests), `sql NAME -e "..."` or `--file`, `list`, `down NAME` or `--all`. Only touches containers whose names start with `zz-` and that carry its label; never pulls an image (exit 3 says which `docker pull` would be needed); refuses a busy port (exit 4). |
| `mssql_gen_scripts.py` (+ `mssql_gen_scripts.sql`) | Writes a re-runnable `schema.sql` and `seed.sql` for the dbo schema of a SQL Server database from the catalog, with `sqlcmd` (no SMO): tables, identity, computed and persisted columns, temporal tables, keys, indexes (unique, included, filtered), defaults, checks, foreign keys, views, procedures, triggers; the seed is parents first, quotes doubled, with the literal styles for money, float, datetimeoffset, hierarchyid, geography and sql_variant. `--disable-triggers`, `--only schema|seed`. Apply the files with `sqlcmd -I -f 65001 -b` from their folder with relative names. The limits are listed at the top of the `.sql` file. |
| `ps_quirks_check.ps1` | Run it in `powershell.exe` and in `pwsh` to see two silent breakages: `\| Select-Object -First N` stopping the script upstream, and Windows PowerShell 5.1 dropping double quotes inside an argument passed to a native program (stdin keeps them). Needs a working python for the second part. |

Windows Python: pass `C:/x` paths (`compare_trees.py` and `spec_item.py` also accept Git Bash's `/c/x`). Each script prints its usage when run without arguments.
